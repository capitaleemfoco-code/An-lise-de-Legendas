O navegador só libera o microfone em páginas com endereço seguro (https). Você abriu o app como arquivo do celular.

  1. Envie este arquivo para um site gratuito, como Netlify Drop (app.netlify.com/drop) ou GitHub Pages.
  2. Abra o link https que o site gerar, no Chrome.
  3. Toque em Iniciar legenda e permita o microfone.
